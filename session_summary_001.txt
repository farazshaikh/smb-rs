## CRITICAL LESSONS (do not re-learn)
1. CAP_LARGE_READX=0x4000, CAP_LARGE_WRITEX=0x8000 (NOT 0x40000000/0x80000000 — bit31=EXT_SEC!)
2. Negotiate response: WordCount=17, 34 bytes byte-packed, ChallengeLength byte at [33],
   challenge bytes in data area at frame[69..77]
3. EXTENDED_SECURITY (bit31) MUST be advertised or modern clients reject sessions;
   negotiate data then = 16-byte GUID only (no challenge); setup does SPNEGO legs
4. Reader::zstring(base) adds cursor pos internally — never pre-add rd.pos to base arg
5. WRITE_ANDX has TWO wire variants (MS-CIFS vs Impacket); rw::pick_layout tries both
6. TRANS2 request: subcmd either in Setup[0] (Impacket) or params[0]+pad (classic);
   param offsets vwv9/10, data offsets vwv12/13
7. READ_ANDX response needs full WC=12 (24B params, 6B reserved tail)
8. Session setup responses: OEM strings always (impacket mis-parses UTF16 there)
9. cargo test --workspace for all tests; smb-auth has MD4/MD5/HMAC vectors (all green)
10. QFILEINFO composite level 0x107 layout verified vs smbd capture (92B form)

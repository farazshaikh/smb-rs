# test/data

Committed conformance results and the history viewer. Regenerated by
`smb-testrunner --record` (see [../README.md](../README.md)).

- `index.html` + `app.js` — static viewer; open directly in a browser.
- `results.json` — aggregate the UI reads (rebuilt every run).
- `results.db` — SQLite store of all runs/results/metrics, keyed by git commit.
- `summary.csv` — one row per run (totals, pass rate, duration).
- `history.csv` — one row per (run, case).
- `runs/<run_id>.json` — full per-run report (the source of truth).

These files are intentionally version-controlled so pass/fail and metric
trends are visible in git history and code review.
